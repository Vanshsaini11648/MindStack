# MindStack manual QA checklist

- [ ] Fresh origin starts empty with no example records.
- [ ] Create/edit notes, reload, and verify persistence.
- [ ] Pin/favourite, archive, trash, restore, duplicate, and permanently delete notes.
- [ ] Create folders and tags; rename them; delete a folder without deleting its notes.
- [ ] Search notes, tasks, and bookmarks with Ctrl/Cmd+K.
- [ ] Link two notes and verify graph nodes and edges.
- [ ] Create/edit/complete/filter/delete tasks; verify calendar due dates.
- [ ] Create flashcards, reveal answers, rate cards, reload, and verify review state.
- [ ] Create and take a quiz; verify saved attempt and score.
- [ ] Add/edit/delete bookmarks; reject invalid URL schemes and duplicate URLs.
- [ ] Export JSON, reject invalid JSON, and import a valid backup after confirmation.
- [ ] Export individual notes and a Markdown bundle.
- [ ] Verify analytics update from actual saved records.
- [ ] Change theme/accent/font and reload.
- [ ] Test desktop, tablet, and mobile layouts.
- [ ] Check console errors, storage quota behavior, and production asset paths.
- [ ] Verify a real Vercel deployment after publishing.

This is a manual checklist, not a claim that every browser interaction has been tested. Automated end-to-end testing and live deployment verification were not available for this build.
